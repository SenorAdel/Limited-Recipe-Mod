# Changelog

This project follows a user-facing changelog. Version tags are for the mod JAR; CurseForge release type is chosen separately when uploading.

## 1.3.8-beta.1

- Introduces the in-game recipe access manager and applied-rule browser.
- Adds independent per-recipe craft and JEI access policies, global disable, and rule on/off controls.
- Adds visual slot editing for common vanilla recipe types, with raw JSON editing for compatible custom recipe serializers.
- Adds a searchable item picker and recipe-type filters.
- Targets Minecraft 26.1.2 on NeoForge and Java 25.

This is the first public beta. Back up worlds before testing recipe overrides.
